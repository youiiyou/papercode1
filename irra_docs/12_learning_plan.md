# 12 学习计划:从零到能自己写出来

> 目标:逐行看懂 IRRA 全部代码,最终能不看源码、从空白文件手写一个等价的 IRRA 训练框架。
> 前提:已读完 01~11 全部文档(或至少走完一遍推荐主线)。
> 总时长:约 **2~3 周**(每天 2~3 小时);赶时间可压缩到 1 周(只做精读不做手写复现)。

---

## 阶段一:建立全局认知(半天)

**目标**:不看代码也能说清楚 IRRA 在做什么。

**阅读**:
1. `01_paper_overview.md` 全文 —— 论文说了什么
2. `HANDOFF.md` §1-4 —— 一分钟速览 + 关键结论

**检验问题**(能回答才算过):
- IRRA 解决什么任务?三大挑战是什么?
- 三个训练分支(IRR / SDM / ID)各自做什么?
- 为什么推理时零额外开销?
- 193 个图像 token 怎么来的?77 个文本 token 是什么?

## 阶段八:手写复现(终极检验,3~5 天)

**目标**:不看源码,从零写出一个能跑通 IRRA 训练的最小框架。

**建议步骤**:
1. **先写数据管线**:JSON → Dataset → collate → DataLoader(参考 03)
2. **再写模型**:CLIP 双塔 + 全局特征提取(参考 04/05)
3. **再加损失**:SDM + ID + MLM(参考 06)
4. **最后拼训练循环**:optimizer + scheduler + 评测 + checkpoint(参考 07/08)

**检验标准**:
- 你的版本能在 CUHK-PEDES 上跑起来
- 前 10 个 epoch 的 loss 曲线趋势与原版一致(不用追求数字完全一致)
- 能解释你写的每一行代码在做什么
